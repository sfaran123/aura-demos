# AURA ERP – demo pages

Static demo pages (example data only), hosted on Render as a static site.

- `public/index.html` – list of demos
- `public/cash-register/` – cash register list and consolidated Z report (PDF / CSV)

To add a demo: create `public/<name>/index.html` and a link in `public/index.html`. Render redeploys on every push.
